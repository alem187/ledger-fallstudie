# Ledger-Fallstudie: schlankes Hilfs-Repository

Durchführung am Arbeits-Mac mit GitHub Copilot Business in VS Code;
technische Auswertung anschließend auf dem Windows-PC.

**Vorbereitungsexport, noch keine Startfreigabe.** Dieses Repository enthält
keine Versuchsergebnisse. Das private Thesis-Repository bleibt maßgeblich.
Die Analyseumgebung und der vollständige Stand V sind noch vorzubereiten.
Der übernommene Protokoll-Quellstand enthält ältere Statusangaben; die tatsächlichen
Startvoraussetzungen müssen vor A1 geprüft und dokumentiert werden.

1. Repository klonen oder ZIP herunterladen und entpacken.
2. Anleitung unter `anleitung/MAC.md` lesen.
3. In VS Code ausschließlich den Unterordner `eingabe` öffnen.
4. Prompt außerhalb dieses Arbeitsbereichs aus `anleitung/PROMPT.txt` kopieren.
5. Nachweise ausschließlich lokal außerhalb des geöffneten Eingabeordners speichern.
   Keine ausgefüllten Formulare, Kontodaten oder Antworten öffentlich hochladen.

`eingabe` enthält genau vier bytegleich übernommene Dateien.
Lizenzhinweise stehen unter `lizenzen`, Zuordnung und SHA-256 unter `herkunft`.
Die Hashes beziehen sich auf Dateiinhalte; das Manifest enthält keine Selbstprüfsumme.

Die vollständige PC-Auswertungsumgebung aus dem großen Vorbereitungsauftrag
ist in diesem Export noch nicht enthalten. Keine Copilot-Anfrage zum Testen senden.
